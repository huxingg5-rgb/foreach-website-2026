# 深圳市恒永达科技股份有限公司（FOREACH）

## 公司简介

深圳市恒永达科技股份有限公司，品牌名称 **FOREACH**，始创于 2012 年，是一家专注于微流体核心部件和液路系统解决方案的研发制造企业。公司证券简称为“恒永达”，证券代码为 **874030**。

FOREACH 围绕设备内部的液体计量、输送、切换、连接、采样和状态检测，研发并制造泵、阀、管路、接头、采样针、传感器及驱动控制组件，为设备制造商提供从单个液路部件到系统匹配的工程支持。

公司服务的主要行业包括：

- 体外诊断（IVD）
- 生命科学
- 实验室自动化
- 高端分析仪器
- 环境监测
- 合成生物
- 医疗设备及其他自动化流体设备

## 主营业务

FOREACH 的主营业务可概括为：

> 微流体系统解决方案设计，以及微流体核心零部件的研发、生产、销售和技术服务。

公司产品用于解决自动化设备中的以下液路任务：

1. 微升级至毫升级液体的精密计量与分配；
2. 试剂、样本、清洗液和废液的输送；
3. 多通道流路切换和快速开关；
4. 管路、泵、阀、针和容器之间的可靠连接；
5. 气泡、压力和液位等液路状态检测；
6. 根据设备空间、介质、接口和控制方式进行定制集成。

## 工程与制造能力

FOREACH 的产品开发和交付工作围绕设备制造商的真实液路需求展开，主要支持以下环节：

- **选型评估**：根据介质、流量、压力、精度、接口、空间和寿命要求推荐产品方向。
- **样品验证**：支持客户在实际设备和液路条件下进行流量、压力、材料兼容和运行稳定性测试。
- **定制开发**：可根据安装空间、接头方向、线束、电压、控制方式和接液材料进行适配。
- **批量导入**：围绕关键尺寸、流量、压力、寿命和一致性建立生产与检验流程。
- **技术支持**：提供从规格确认、安装调试到异常分析的工程协作。

## 典型应用

### 体外诊断（IVD）

用于样本处理、试剂分配、反应液输送、清洗、废液排放、流路切换、气泡检测和压力监测。

### 生命科学

用于样本前处理、微量移液、试剂制备、培养液输送和自动化实验工作站。

### 实验室自动化

用于自动加液、液体转移、清洗循环、废液管理和模块化液路集成。

### 分析仪器

用于高压进样、精密计量、多通道切换、压力检测和检测前处理。

### 环境监测

用于水质取样、试剂投加、液体输送、清洗和排液。

### 合成生物

用于多通道试剂分配、培养液路、连续流动和自动化流路切换。
