## 图片建议

建议尺寸：
- 600 × 380 px
- 或 1200 × 760 px

建议格式：
- webp

视觉建议：
- 不要纯人物大图
- 优先使用仪器局部、液路、管路、接头、泵阀、实验台工程调试场景
- 图片要偏干净、浅色、专业
- IVD 相关图片可以体现中国工程师，但人物不要成为主体
