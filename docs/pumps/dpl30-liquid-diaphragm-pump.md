# DPL30 300 mL/min 液体隔膜泵

## 产品概述

DPL30 是 FOREACH（深圳市恒永达科技股份有限公司）开发的紧凑型液体隔膜泵系列，面向设备内部的液体供给、自吸输送、清洗循环和废液处理等应用，流量可达 **300 mL/min**。

该系列可选 DC 12V 或 DC 24V、直流有刷或直流无刷电机，并提供 EPDM 或 PTFE + FFKM 等接液材料组合。接口形式、接口方向、出线方式、线束和特殊结构可根据设备需求进行确认。

DPL30 可作为医疗设备、IVD 仪器、实验室自动化设备、环境监测设备和其他自动化液路系统中的液体输送部件。是否适合某种具体液体，需要结合介质成分、浓度、温度、背压、工作时间和接液材料进行兼容性验证。

## 工作原理

DPL30 通过电机带动偏心机构，使柔性膜片往复运动：

1. 膜片后移时，泵腔体积增大并形成负压，入口阀打开，液体被吸入泵腔；
2. 膜片前移时，泵腔体积减小，入口阀关闭，出口阀打开，液体被排出；
3. 电机持续运行，使吸液与排液循环进行，从而形成连续液体输送。

隔膜将驱动机构与液体腔分开，液体主要接触膜片、阀片和泵头，因此材料选择直接影响介质适用性和使用寿命。

## 如何选择 DPL30

### 1. 选择 12V 还是 24V

电压应优先匹配整机电源系统和控制架构。12V 与 24V 并不简单代表性能高低，实际工作点还与电机、负载、管路和控制方式有关。

- 设备已有 12V 电源：优先评估 12V 型号；
- 工业或自动化设备采用 24V 电源：优先评估 24V 型号；
- 存在长线供电、启动电流或电磁兼容要求时，应结合整机电气设计确认。

### 2. 选择有刷还是无刷电机

**有刷电机**通常适合成本敏感、工作时间较短或间歇运行的设备。

**无刷电机**通常更适合长时间运行、启停频繁、对寿命和维护要求较高的设备。

选型时应比较：

- 每天运行时间；
- 连续或间歇工作；
- 启停次数；
- 预期整机寿命；
- 噪音和电磁兼容要求；
- 成本与维护策略。

### 3. 选择 EPDM 还是 PTFE + FFKM

**EPDM 膜片与阀片**适合部分水基液体、清洗液和常规液路，但不应仅根据“水基”判断兼容性。

**PTFE 膜片 + FFKM 阀片**用于对化学兼容性要求更高的液路，但也不能理解为适用于所有酸、碱、溶剂或混合试剂。

材料确认至少需要以下信息：

- 液体名称和配方；
- 各成分浓度；
- 工作温度；
- 接触时间；
- 是否连续运行；
- 是否存在清洗剂或消毒剂；
- 是否要求长期浸泡或仅短时通过。

### 4. 确认流量与背压

300 mL/min 是 DPL30 系列的代表流量能力，不代表泵在所有背压、管径和介质条件下都保持相同流量。

实际流量会受到以下因素影响：

- 管路内径和长度；
- 接头、过滤器和阀的流阻；
- 出口背压和吸入高度；
- 液体黏度、密度和温度；
- 电压和电机转速；
- 膜片与阀片材料；
- 泵的安装方向和运行时间。

建议在整机真实液路中进行样品测试，而不是只依据空载流量选择。

## 常见问题

### DPL30 的 300 mL/min 是固定流量吗？

不是。300 mL/min 是系列代表流量能力，实际流量会随背压、管路、介质、电压和电机工况变化。需要在目标液路中验证实际工作点。

### DPL30 可以用于医疗设备吗？

可以作为医疗设备和 IVD 仪器内部的液体输送部件进行评估，常见任务包括清洗液供给、废液排放和液体循环。具体应用必须验证介质兼容、性能和整机法规要求。

### 有刷和无刷版本如何选择？

间歇运行、成本敏感场景可优先评估有刷版本；长时间运行、启停频繁或寿命要求较高的设备可优先评估无刷版本。

### EPDM 与 PTFE + FFKM 如何选择？

需要根据液体配方、浓度、温度和接触时间判断。不能只根据材料名称或简单的耐酸碱描述选择。

### DPL30 能输送腐蚀性液体吗？

部分材料组合可能适合特定腐蚀性介质，但必须进行材料兼容性确认和样品测试，不能概括为可输送所有腐蚀性液体。

### DPL30 可以干转吗？

是否允许干转、允许时长及其对寿命的影响应以具体型号规格书和工程确认结果为准。长期无液运行可能加速膜片、阀片或其他部件磨损。

### 接口和线束可以定制吗？

可以评估倒刺、螺纹、接口方向、出线方式、线束和特殊结构等配置，但需要确认组合可制造性、最小订单量和验证要求。

### 为什么理论型号很多，但主推型号只有 8 个？

型号规则允许电压、电机、出线、接口、方向和材料进行组合，因此理论数量较多。主推的 8 个型号覆盖最常见的电压、电机和接液材料选择，其他配置按项目确认。
